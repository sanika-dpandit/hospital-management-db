# Hospital Management Database
**ISTE 230 | RIT Dubai | Group 3**  
Sanika Pandit · Praislin Peter · Aamina

## Overview
A relational database system for managing hospital operations including 
patient appointments, medical records, prescriptions, lab reports, and billing.

## Database Schema
10 tables: Department, Doctor, Patient, Appointment, LabTech, 
LabReport, Prescription, Service, Invoice, InvoiceService

## Tech Stack
- MySQL
- Lucidchart (ER Diagram)

## Files
- `schema.sql` – table definitions
- `data.sql` – sample data
- `queries.sql` – relational algebra + SQL queries/functions
- `docs/` – project report and presentation
